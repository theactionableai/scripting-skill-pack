# Save the framework

When a script lands, save it so the next one starts from here. The first script takes an hour. The next takes 40 minutes. Over time, all the user needs to show up with is a topic and one or two containers.

Append this block to `my-context/saved-frameworks.md`. Keep it short.

```markdown
## [Short name for this framework] (YYYY-MM-DD)

- Topic: [one line]
- Pain or desire it hits: [one line, from icp.md]
- Container: [the outlier or shape it was built on, with link if any]
- Hook shape: [the fill-in version, subject removed]
  e.g. "If you want to [dream outcome with number], you need to be doing these [N] things. But almost every [person like the viewer] misses the [last] one, and it's why they [pain]. So let me show you what it is."
- Final hook: [the exact words]
- Beat 2 move: [what it did, one line]
- Teach format: [named framework + how many steps]
- Positioning line: [the "it's not your fault" line]
- CTA: [save / send / keyword, and what the keyword sends]
- What made it land: [one or two lines in the user's own words]
- Result (fill in after posting): [views, saves, comments, leads]
```

When a new session starts, scan this file first. If a saved framework fits the new topic, offer it before building from scratch.
